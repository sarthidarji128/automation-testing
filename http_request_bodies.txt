# HTTP request bodies for this project

Endpoint: POST /api/state
Content-Type: application/json

Notes:
- The app expects the entire app state JSON. Typical flow: GET /api/state -> modify the JSON (set `currentUser` or add a user) -> POST the full JSON back to /api/state.

Example: Login (set current user to Alice)
{
  "users": [
    {"username": "alice", "name": "Alice Smith", "password": "123"},
    {"username": "bob", "name": "Bob Jones", "password": "123"}
  ],
  "messages": [],
  "groups": [],
  "currentUser": {"username": "alice", "name": "Alice Smith"}
}

Example: Sign Up (add a new user and auto-login)
{
  "users": [
    {"username": "alice", "name": "Alice Smith", "password": "123"},
    {"username": "bob", "name": "Bob Jones", "password": "123"},
    {"username": "newuser", "name": "New User", "password": "secret"}
  ],
  "messages": [],
  "groups": [],
  "currentUser": {"username": "newuser", "name": "New User"}
}

Quick curl examples:

Login (example):
curl -X POST "http://127.0.0.1:8000/api/state" \
  -H "Content-Type: application/json" \
  -d '{"users":[{"username":"alice","name":"Alice Smith","password":"123"}],"messages":[],"groups":[],"currentUser":{"username":"alice","name":"Alice Smith"}}'

Signup (example):
curl -X POST "http://127.0.0.1:8000/api/state" \
  -H "Content-Type: application/json" \
  -d '{"users":[{"username":"alice","name":"Alice Smith","password":"123"},{"username":"newuser","name":"New User","password":"secret"}],"messages":[],"groups":[],"currentUser":{"username":"newuser","name":"New User"}}'

Recommendation: First `GET /api/state` to retrieve the current JSON, update `users`/`currentUser` as needed, then `POST` the full JSON back so you don't accidentally overwrite data.
